# Holberton School - Interview Preparation

Algorithm problems in Python 3, practiced for technical interviews at Holberton School.

## Problems

| Folder | Problem |
| --- | --- |
| [lockboxes](lockboxes/) | Given boxes that contain keys to other boxes, check if all boxes can be opened |
| [log_parsing](log_parsing/) | Read log lines from standard input and print statistics (`0-stats.py`) |
| [minimum_operations](minimum_operations/) | Find the fewest operations needed to reach exactly `n` characters with Copy All and Paste |
| [nqueens](nqueens/) | Place N queens on an N x N chessboard so that none can attack another |
| [pascal_triangle](pascal_triangle/) | Build Pascal's triangle of size `n` |
| [utf8_validation](utf8_validation/) | Check if a list of integers is a valid UTF-8 encoding |

## Requirements

- Python 3
- Code follows the `pycodestyle` style
- Each function has a docstring

## How to run

Each folder has a main file starting with `0-`. Run it with a test file or from the terminal:

```bash
python3 0-nqueens.py 4
```

## What I practiced

- Breaking a problem into steps before coding
- Choosing a simple data structure for the problem
- Thinking about edge cases and time complexity
- Writing clean and readable Python
